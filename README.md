\# Чудо Обувь — система оформления заказа обуви



Настольное приложение на C# (WPF, .NET Framework 4.8) с базой данных SQL Server.



\## Функциональность



\- Вход по логину без пароля и вход как гость.

\- Каталог обуви: изображение, категория, производитель, состав, цена, скидка 25% на модели без заказов в прошлом месяце, подсветка моделей с остатком 3 пары и меньше.

\- Поиск, сортировка по цене и фильтр по категории для авторизованных пользователей.

\- Карточка товара, выбор размера и количества, корзина и оформление заказа со списанием остатков.

\- Менеджер и администратор: список заказов, состав заказа, добавление и удаление заказа.

\- Администратор: изменение даты заказа и удаление позиций заказа.



\## Запуск



1\. В SQL Server Management Studio выполнить скрипт `Database/ChudoObuv.sql`.

2\. Запустить `Release/ChudoObuv.exe`.



Подключение к базе: `localhost\\SQLEXPRESS`, база `ChudoObuv`.
